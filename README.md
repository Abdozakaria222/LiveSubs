# مترجم القنوات (LiveSubs) – Android TV

بيلتقط صوت اللي شغال على البوكس (فيلم/مسلسل)، ويعرض الترجمة العربي فوق الصورة.

## محركات الترجمة
- **Gemini**: دقة عالية ويكتشف اللغة لوحده، بس فيه حد يومي مجاني.
- **أوفلاين** (Vosk + Google ML Kit): بلا حدود ومن غير نت، بس دقة أقل ولازم تختار لغة الفيلم.
- **Gemini + تحويل تلقائي** (مُستحسن): يشتغل بـ Gemini، ولو الحد خلص أو النت فصل يحوّل للأوفلاين لوحده.

للأوفلاين: اختار اللغة ودوس "تنزيل موديل الأوفلاين" مرة واحدة وإنت متصل بالنت (حوالي 40-50 ميجا + 30 ميجا للترجمة).

## بناء الـ APK
1. ارفع الفولدر ده على ريبو GitHub جديد.
2. تبويب Actions → Build APK → هيشتغل تلقائياً مع كل push (أو Run workflow).
3. نزّل `LiveSubs-apk` من Artifacts وسطّبه على البوكس.

## التشغيل
1. هات مفتاح مجاني من https://aistudio.google.com/apikey
2. افتح التطبيق → حط المفتاح → تشغيل الترجمة.
3. وافق على: العرض فوق التطبيقات، الصوت، وإذن تسجيل/مشاركة الشاشة.
4. ارجع للقناة، والترجمة هتظهر تحت.

## ملاحظات
- محتاج Android 10 أو أحدث.
- بعض التطبيقات (Netflix وأمثاله) بتمنع التقاط صوتها. لو مفيش ترجمة، علّم على خيار الميكروفون.
- لو البوكس ماعندوش شاشة صلاحية العرض فوق التطبيقات:
  `adb shell appops set com.abdo.livesubs SYSTEM_ALERT_WINDOW allow`
- لو ظهرت رسالة تجاوز حد الطلبات، زوّد "أقصى طول للمقطع" لـ 10 ثواني أو غيّر الموديل.
